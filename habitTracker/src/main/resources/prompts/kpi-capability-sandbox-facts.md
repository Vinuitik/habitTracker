Execution environment for the script: python 3.12 STANDARD LIBRARY ONLY (no requests, no pip), read-only filesystem, ~30s timeout. A module-level string constant TARGET_DATE = "YYYY-MM-DD" is prepended before your code. The script must print the KPI value for TARGET_DATE as a plain number on the LAST line of stdout (extra earlier lines are ignored).
NETWORK: by default there is none. The ONLY network access is to the exact hostnames listed in the approved declaredCapabilities.network (https on 443 or http on 80, any path on those hosts), reached through a mandatory HTTP proxy that is already configured in the HTTPS_PROXY/HTTP_PROXY environment variables. Use urllib.request ONLY: urlopen() picks the proxy (and its credentials) up from the environment automatically, so do not set proxies yourself, do not print or log them, and do NOT use http.client, socket, or ssl directly (they bypass the proxy and will fail). Any other host, an IP address, or a non-80/443 port is denied (you will see HTTP 403 / 'Tunnel connection failed'). Always pass timeout=15 to urlopen. Example: urllib.request.urlopen(urllib.request.Request('https://api.example.com/v1/x', headers={'Authorization': 'Bearer ' + os.environ['API_TOKEN']}), timeout=15).
SECRETS: each name in the approved declaredCapabilities.secrets is available as an environment variable with EXACTLY that name (os.environ['NAME']). Never print, log or return a secret. No other secrets exist.
